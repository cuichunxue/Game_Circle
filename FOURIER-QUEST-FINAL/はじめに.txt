FOURIER QUEST — 1.2

【PCで遊ぶ】
ZIPを展開して、一番上の index.html をブラウザで開きます。
音は画面をクリックしてから有効になります。
ローカルファイルの保存動作はブラウザにより異なります。

【iPhone・iPad】
ZIPは「ファイル」アプリで保存・展開できます。
ゲームは公開サイトをSafariで開く方法をおすすめします。
https://fourier-quest.cuichunxue1984.chatgpt.site
公開サイトは現在、所有者限定です。

【収録】
index.html : JavaScript・CSSを埋め込んだPC用
web/ : GitHub Pagesなどの静的Web配信用（内容を公開フォルダへ配置）
source/ : React / TypeScriptの編集用ソースとテスト

【編集】
sourceフォルダで npm ci、npm run build を実行します。
npm test ですべてのテストを実行できます。npm run release で web/ と index.html を作り直します。
