## v1.1 のジャーニー（コードと実画面から確認した現状）

| フェーズ | 子どもの行動 | 気持ち | 見つかった課題（根拠） |
|---|---|---|---|
| **① 出会い**（最初の10秒） | 画面を開く → 文字を読む → どこを触る？ | 😐 わくわく半分・とまどい半分 | 説明文が多く、操作の入口が小さい。ST1は半径10の小さな円で、「円のふちを動かそう」は右下の小さな文字だけ（`app.tsx` canvas-legend）。つかめる場所が光らない |
| **② はじめての操作** | ふちをドラッグ／スライダーを動かす | 🙂 動くのは楽しい | 近づいているか遠ざかっているかが、右側の％を見ないと分からない（スマホでは画面外）。音の高さは「値」で決まっていて、正解への近さと無関係（`audio.note(Math.round(v/20))`） |
| **③ はじめてのクリア** | 70%をこえる | 😃 → 😐 | 演出は2.2秒の文字表示のみ。「つぎへ」はワークベンチ内で、スマホでは下にスクロールしないと見えない。次に何をすればいいかが途切れる |
| **④ 学校（ST2〜7）** | 大きさ・速さ・向き・角度を1つずつ学ぶ | 😃 ひらめき | ここは良い設計。1ステージ1テーマ |
| **⑤ 森〜城（ST8〜40）** | 同じ操作をくり返す | 😩 飽き・作業感 | **最大の問題**：ST8〜40の30ステージ（節約を除く）は、すべて「円1を150→55、円2を100→24にする」同じパズル（`generate-stages.mjs`）。お題文も33ステージで同じ「ひとつ変えて、形のちがいを見つけよう。」。速さ・角度のスライダーは触ると壊れるだけの“おとり”になっている |
| **⑥ ごほうび・収集** | ★を集める | 😐 | ★6・★12で色が2つ解放されたら、その後108個の★に新しいごほうびがない。ワールドクリアの節目演出もない |
| **⑦ 自由創作** | 円を足す・絵を描いて円にする | 🤩 すごい！ | 「描いた絵が円で動く」は最高の“わぁ！”体験。ただしクエスト側から誘導が弱い |
| **⑧ また来る** | 次の日に開く | 🙂 | 「おかえり」とつづきから再開できるのは良い。ただ「今日はこれをやろう」という次の目標が見えにくい |

## 改善の方針

「**わかる → できた！ → もっとやりたい**」のループを、最初の10秒から最後のステージまで切らさない。

| 優先 | フェーズ | 打ち手 | ねらう気持ち |
|---|---|---|---|
| **P0** | ⑤ | **40ステージを作り直す**。ワールドごとにテーマを変え、まちがっている場所（大きさ・速さ・向き・角度）と数を毎回変える。お題文と「発見」もステージごとに書き下ろし。W3・W4は「ずれている円は○こ」の**まちがいさがし**にして、全部の円を触れる理由をつくる | 「今回はどこがちがう？」という謎解き |
| **P0** | ③ | **クリアカード**：キャンバスの上に★が順番にポンと出て、「つぎのステージへ」ボタンをその場に表示。紙ふぶき（動きをひかえめ設定では出さない）。ワールドの最後は「ワールドクリア！」 | 達成感と、次へのなめらかな流れ |
| **P0** | ① | **つかむ場所を光らせる**：ドラッグできる点に脈打つリングと「ここを ひっぱってね」。つかめる半径を24→32pxに広げ、つまみも大きく | 最初の10秒で迷わない |
| **P1** | ② | **あったか・つめたい**：キャンバス上にぴったり度を常に表示し、近づくと「あったかい！」・音が高くなる、遠ざかると「つめたい…」。60%をこえたら「おしい！」 | 試行錯誤そのものが楽しい |
| **P1** | ② | **カチッと吸いつく**：ドラッグで正解の近く（大きさ±2・角度±6°）に来たら吸いつき、カチッと音 | 指の細かい操作が苦手でも「ぴったり」を味わえる |
| **P1** | ⑥ | **シール帳**（12種）：はじめてのクリア、ワールド卒業×4、★30/★60/★120、自力で★★★、節約名人、はじめての作品、コレクター。ゲット時にお知らせ | 集める楽しさ、長期目標 |
| **P1** | ⑥ | **ひかりの色を6色に**（★6/12/24/45/80）。「にじ」は色が流れる | 中盤以降もごほうびが続く |
| **P2** | ⑧ | 冒険マップで「つぎにあそぶステージ」に NEW を表示 | 開いたらすぐ次の目標が分かる |
